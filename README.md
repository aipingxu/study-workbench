# 学习工作台项目

> S 的个人学习工作台集合，包含多个不同类型的学习平台。

## 项目结构

| 分支 | 学习台 | 说明 |
|------|--------|------|
| `main` | 项目主页 | README + 项目说明 |
| `primary-study` | 小学四升五学习台 | 沪教版教材，语数英三科，每日打卡，移动端优先 |
| `business-english` | 商务英语×临床系统英语学习台 | 零基础成人英语，口语+词汇，12周课程体系 |

## 技术栈

- **PWA**（渐进式 Web 应用）：Safari"添加到主屏幕" + Chrome/Edge 安装
- **Web Speech API**：TTS 语音朗读，支持中英文、变速
- **Chart.js**：学习统计可视化
- **localStorage**：本地状态管理
- **Service Worker**：离线缓存
- **数据同步**：JSON 导出/导入实现跨设备同步

## 使用方法

1. 切换到对应分支查看代码
2. 用浏览器打开 `index.html`，或部署到云端访问
3. iPhone：Safari 打开 → 分享 → 添加到主屏幕
4. Windows：Chrome/Edge 打开 → 安装为应用

## 分支详细说明

### primary-study（小学四升五学习台）
- 适合：上海小学四年级升五年级学生
- 教材：沪教版（数学）、统编版（语文）、牛津上海版（英语）
- 功能：每日打卡、课程解锁、音频讲解、B站视频链接、进度统计
- 配色：Indigo(#6366F1) + Amber(#F59E0B)
- 自定义图标：用户生日图片

### business-english（商务英语×临床系统英语学习台）
- 适合：零基础成人，需提升商务英语口语和临床医疗系统英语
- 课程：12周×5天 = 60课口语 + 60课词汇（600个单词）
- 三阶段：基础英语 → 商务沟通 → 临床研究/系统验证专业英语
- 功能：TTS朗读、闪卡翻转、计时器、打卡统计、数据导出
- 配色：Teal(#0F766E) + Amber(#F59E0B)

## 部署

每个分支的代码可直接部署为静态站点，推荐使用 CloudStudio 部署。
